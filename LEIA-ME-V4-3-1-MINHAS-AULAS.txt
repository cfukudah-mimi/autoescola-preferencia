AUTOESCOLA PREFERÊNCIA — V4.3.1 — CORREÇÃO MINHAS AULAS

O QUE FOI CORRIGIDO
- O login do aluno continua usando validar_login_aluno e permanece funcionando.
- A tela Minhas Aulas agora usa a função listar_aulas_aluno.
- Isso evita o bloqueio causado pelo RLS da tabela agendamentos.
- Mostra data, horário, tipo, instrutor, veículo e status.

ANTES DE TESTAR O SITE
1. Abra o Supabase > SQL Editor.
2. Abra o arquivo CORRECAO-MINHAS-AULAS.sql deste pacote.
3. Copie TODO o conteúdo para o SQL Editor.
4. Clique em Run.
5. Depois substitua a pasta antiga no GitHub por esta pasta corrigida.
6. Aguarde o GitHub Pages atualizar e teste novamente.

IMPORTANTE
Se você apenas subir os arquivos no GitHub sem executar o SQL, a página Minhas Aulas ainda não conseguirá listar os agendamentos.
